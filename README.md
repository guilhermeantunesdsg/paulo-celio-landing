# Dr. Paulo Célio — Deputado Estadual

Landing page de campanha "Nossa Terra, Nossa Voz".

Página estática, autocontida (`index.html`), sem dependências de build ou backend.

## Publicar com GitHub Pages

1. Vá em **Settings > Pages** neste repositório.
2. Em "Build and deployment", selecione **Deploy from a branch**.
3. Branch: `main`, pasta: `/ (root)`.
4. Salve — o site fica disponível em poucos minutos na URL indicada.
